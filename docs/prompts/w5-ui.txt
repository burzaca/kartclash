The HUD must be built for SPLIT SCREEN: one fully independent HUD per viewport, positioned by
setViewport(i, {x,y,w,h}) in canvas pixels measured from the top of the canvas. Every element must be
absolutely positioned inside its own viewport container and scale with the viewport size (use a CSS
custom property for the scale that update() sets, so nothing is hardcoded to full-screen px).
pointer-events: none on everything. Class names prefixed kc-. All CSS in one template string injected
into a single style element by the module — no external stylesheet, no images, no webfonts, no
framework, no build step.

The HUD per player must contain, in a designed arcade layout (not a plain text dump):
 - big position badge (1st / 2nd / 3rd ...) with the racer colour,
 - lap counter x/3,
 - an item slot: a rounded box with the item drawn procedurally — build inline SVG for mushroom,
   triple stacks, green shell, red shell, banana, fake item (question box), lightning and star. They

 - time, last lap, best lap, and the gap to the leader for each racer in a compact standings strip,
